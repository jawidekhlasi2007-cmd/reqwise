# Screenshots

Capture these after your first run and save them here with these names so the main README shows them:

| File | What to capture |
|---|---|
| `landing.png` | http://localhost:3000, the hero with the annotated requirement |
| `dashboard.png` | The dashboard with a document loaded and the agent pipeline running or finished |
| `report.png` | A report page showing the score tiles and the findings charts |

Recommended: a 1440 × 900 browser window, dark background, PNG format.
